Primer proyecto Estructura del CIM Tipos de campo Reglas OCL Entregables y BD

Tu primer proyecto

  1. Abre Proyectos → Nuevo proyecto. Ponle un nombre, por ejemplo Solicitudes de mantenimiento, y selecciona Proceso básico.
  2. En CIM → Campos y negocio, usa + Añadir campo directamente en la tabla para agregar atributos sin tocar el JSON, o usa los botones + Actor, + Estado, + Transición y + Regla OCL del panel lateral.
  3. Pulsa Validar y ver PIM para inspeccionar el modelo lógico independiente de plataforma (clases UML/Ecore, tipos EString/EInt, multiplicidades, firmas de operaciones y archivo .ecore).
  4. Sigue con Ver PSM para elegir entre Lista de casos (bandeja) y Tablero por estado viendo cómo cambia la arquitectura visual, los controles HTML5 y el esquema relacional SQL (.sql).
  5. Pulsa Generar aplicación o Abrir app en pestaña ↗ para ejecutar la aplicación con persistencia en Base de Datos (IndexedDB) y conexión directa a archivo (.db.json / .sql).

Estructura del CIM

ClaveQué debes definir
version, idUsa la versión 1 y un identificador como mantenimiento.
nombre, objetivo, entidadTítulo de la aplicación, finalidad y nombre de la entidad, por ejemplo Solicitud.
actoresQuién participa. Cada actor tiene id y nombre.
datosLos campos del caso. Cada uno declara id, nombre, tipo y, si aplica, requerido u opciones.
inicioEl actor que crea el caso, su primer estado y el nombre de la acción inicial.
estadosLas etapas con id y nombre. Marca los finales con "final": true.
transicionesAcciones con id, nombre, actor, desde y hasta. El actor y ambos estados deben existir.
oclLista de reglas OCL (invariantes inv, precondiciones pre y postcondiciones post).

Reglas OCL ampliadas

El compilador soporta invariantes (inv), precondiciones (pre) y postcondiciones (post) sobre campos de tipo Entero, Texto, Seleccion, Booleano y Fecha, comparaciones entre dos campos (self.a >= self.b) y conectores lógicos and, or e implies.

context Prestamo inv CantidadValida: self.cantidad >= 1 and self.cantidad <= 5
context Prestamo::aprobar() pre MotivoSuficiente: self.motivo.size() >= 8
context Compra inv PrioridadDocumentada: self.prioridad = 'urgente' implies self.documentado = true

Entregables por etapa y Base de Datos

  1. CIM: Descarga el modelo .cim.json, el diagrama vectorial .svg y la especificación .cim.mmd (Mermaid).
  2. PIM: Descarga el metamodelo estándar Eclipse EMF .pim.ecore (XMI), el archivo formal .pim.ocl y .pim.json.
  3. PSM: Descarga el esquema relacional .psm.sql (con tablas y restricciones CHECK derivadas de OCL), .psm.schema.json y .psm.json.
  4. Aplicación (M2T): Ábrela en una pestaña dedicada, conéctala a un archivo local .db.json o exporta/importa volcados .sql y .db.json respaldados en IndexedDB.
