Tu primer proyecto

  1. Abre Proyectos → Nuevo proyecto. Ponle un nombre, por ejemplo Solicitudes de mantenimiento, y selecciona Proceso.
  2. En CIM → Campos, usa + Añadir campo. Despliega Proceso de negocio para editar actores, estados y transiciones, o Restricciones OCL para añadir una regla. También puedes usar Diagrama para editar el flujo.
  3. Pulsa Validar y ver PIM. Comprueba los datos en Campos y tipos. Consulta las relaciones en Clases y las restricciones en Reglas OCL.
  4. Sigue con Ver PSM. En Interfaz elige una lista o un tablero. Mapeo muestra qué control se genera por campo y Datos y SQL reúne el almacenamiento y el esquema.
  5. Pulsa Generar aplicación para probar el flujo. Usa Abrir en otra pestaña cuando quieras conservar los cambios en el navegador.

Elige Catálogo CRUD para trabajar con registros o Proceso con catálogo para vincular solicitudes a un inventario. Las filas con Catálogo vinculado se configuran en Editar JSON, dentro de integracion.catalogo.

Estructura del CIM

ClaveQué debes definir
version, idUsa la versión 1 y un identificador como mantenimiento.
nombre, objetivo, entidadTítulo de la aplicación, finalidad y nombre de la entidad, por ejemplo Solicitud.
actoresQuién participa. Cada actor tiene id y nombre.
datosLos campos del caso. Cada uno declara id, nombre, tipo y, si aplica, requerido u opciones.
inicioEl actor que crea el caso, su primer estado y el nombre de la acción inicial.
estadosLas etapas con id y nombre. Marca los finales con "final": true.
transicionesAcciones con id, nombre, actor, desde y hasta. El actor y ambos estados deben existir.
oclLista de reglas OCL (invariantes inv, precondiciones pre y postcondiciones post).

Reglas OCL

El compilador implementa un subconjunto de OCL que admite invariantes (inv), precondiciones (pre) y postcondiciones (post) sobre campos de tipo Entero, Texto, Seleccion, Booleano y Fecha, comparaciones entre dos campos (self.a >= self.b) y conectores lógicos and, or e implies.

context Prestamo inv CantidadValida: self.cantidad >= 1 and self.cantidad <= 5
context Prestamo::aprobar() pre MotivoSuficiente: self.motivo.size() >= 8
context Prestamo inv PlazoParaVariasUnidades: self.cantidad > 2 implies self.dias <= 10

Las reglas de operación se verifican sobre los datos del caso antes de confirmar la transición. En PIM → Reglas OCL puedes desplegar cada regla para ver su expresión y cómo la interpreta el compilador.

Archivos y datos

Abre Archivos y trazabilidad desde cualquier etapa para descargar lo generado o seguir cómo se transforma un elemento del CIM.

  1. CIM: Descarga el modelo .cim.json, el diagrama vectorial .svg y la especificación .cim.mmd (Mermaid).
  2. PIM: Inspecciona y descarga la representación .pim.ecore y las reglas .pim.ocl. También puedes descargar .pim.json.
  3. PSM: Descarga el esquema relacional .psm.sql (con tablas y restricciones CHECK derivadas de OCL), .psm.schema.json y .psm.json.
  4. Aplicación. Descarga el HTML desde Archivos y trazabilidad. En la aplicación, usa Gestionar datos para guardar o restaurar una copia .db.json y exportar un volcado para SQLite. La vista previa tiene datos temporales. Usa la aplicación en una pestaña independiente para conservar los cambios en el navegador.
